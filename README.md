# CORE-NEXUS // Multi-Agent Tactical AI Command Center

A real-time, voice-enabled multi-agent command center built around a reactive tactical interface with five specialized personas (**J.A.R.V.I.S.**, **F.R.I.D.A.Y.**, **SANDRA**, **VISION**, and **ULTRON**), shared session memory, live voice responses, and a 3-slot saved sessions vault[cite: 13].

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your API keys.
3. Start the server: `python -m uvicorn main:app --reload` and open `http://127.0.0.1:8000`[cite: 7, 8].
